## Productivity app for neurodivergent users
### React Native, Expo, Supabase

## Estimated Release Date
1st January 2027. ✅

## How to run it
npx expo start

# What is it and what problem does this solve?
A mobile app designed to help neurodivergent users (particularly those with ADHD) build sustainable routines by addressing time blindness and task-initiation difficulty — both well-documented executive functioning challenges.

Users track tasks using built-in timers and stopwatches, with session data stored and analyzed to surface patterns over time — helping identify what routines actually work for an individual's brain, rather than applying generic productivity advice.

Built independently using React Native and Expo for (eventual) cross-platform mobile development, with Supabase handling backend data storage and user authentication.
